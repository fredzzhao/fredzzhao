### 📊 Featured Projects
*Personal projects on public Kaggle datasets.*

**[DataCo Supply Chain Analysis Dashboard](https://github.com/fredzzhao/DataCo-Supply-Chain-Analysis-Dashboard)** · SQL Server · T-SQL · Power BI · DAX
3-page Power BI dashboard on 180K+ order lines with T-SQL validation. It shows that late delivery comes from shipping-mode promises, not geography: First Class runs late on 95% of lines because it averages 2 days against a 1-day schedule.

**[Demand Forecasting & Inventory Optimization Engine](https://github.com/fredzzhao/End-to-End-Supply-Chain-Forecasting-with-PySpark)** · Python · PySpark · Spark MLlib
Weekly sales forecasts for 17 product sub-categories, tested against naive and moving-average baselines, then turned into safety buffers at a 95% service level.
